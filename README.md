# E-Commerce Frontend App

A modern and responsive e-commerce frontend built using React and Vite. The application showcases a clean product catalog with pricing, promotional banners, and a static “Add to Cart” interface, simulating a shopping experience.

## 🔗 Live Demo

[https://rishio5.github.io/ecommerce_app](https://rishio5.github.io/ecommerce_app)

## Features

- Homepage with seasonal promotional banner
- Responsive product grid layout
- Static product details (image, title, price)
- Add to Cart button (non-functional placeholder)
- Simple header and footer layout
- Fully responsive design

## Technologies Used

- React
- Vite
- Tailwind CSS
- GitHub Pages (for deployment)
